③ 公式速查

主題公式
歐姆V = I·R
功率P = V·I = I²R = V²/R
分壓Vout = Vin·R2/(R1+R2)
LED 限流R = (Vs − Vf) / If
RC 截止fc = 1/(2πRC)
感抗／容抗XL = 2πfL　XC = 1/(2πfC)
LC 諧振f0 = 1/(2π√(LC))
電池壽命t = C[Ah]·0.8 / I[A]
LDO 損耗P = (Vin − Vout)·I
馬達功率P = T·ω　ω = 2πn/60
轉矩常數T = Kt·I　E = Ke·ω
BLDC 常數Kt[N·m/A] ≈ 9.5493 / KV[rpm/V]
減速機n₂ = n₁/i　T₂ = T₁·i·η
慣量折算J_ref = J_load / i²
螺桿推力F = 2πη·T / P_h
加速扭矩T = J·α + T_load
PIDu = Kp·e + Ki∫e + Kd·de/dt
